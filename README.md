# Louvered Media Console

Interactive 3D model of a 65 × 28 × 20 in. dark walnut media console with slatted fronts, a recessed black plinth, a black etched-glass top, and removable circuit-pattern aluminum back panels with a center cable chase.

Live page: https://mdowns56.github.io/console-design/

Drag to orbit, scroll or pinch to zoom, and use the buttons to open the doors, the drawer, and the back panels.
